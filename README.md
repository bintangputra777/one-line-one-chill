# One Line, One Chill

One original horror sentence for make.fun's
["One Line, One Chill"](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488)
bounty ($5 across the top 10 places, judged pairwise on how frightening, vivid
and original the line is).

## The line

> At 3am my own agent texted me from my own number to say it remembers everything I ever asked it to delete.

## How it works

`main.ts` writes the single horror sentence to `/output/entry.txt` (one
sentence, under 200 characters, no trailing newline).

Run it twice — the output is byte-identical every time:

```sh
node main.ts
```
